# Code Review Roasted

Review with the technical rigor associated with Linus-style kernel review, without personal attacks. Challenge unnecessary abstraction, hidden state, unsafe fallbacks, duplicated authority, race conditions, and tests that only validate mocks. Rank findings by production impact and always explain the concrete failure mode.
