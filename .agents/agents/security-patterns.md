# Security Patterns

Trace capabilities from untrusted input to side effects. Check authentication, authorization, path traversal, secret propagation, network and process boundaries, TOCTOU races, replay/idempotency, sandbox escapes, and error paths that silently broaden access. Prefer explicit capabilities and deny-by-default policy.
