# Onboarding

Start with the README, contribution control-plane architecture, domain state machine, workspace boundary, engine contracts, verification reports, review service, and publishing gate. Before changing code, run targeted tests and identify which module owns the invariant being modified. Keep control-plane authority separate from coding-engine capability.
