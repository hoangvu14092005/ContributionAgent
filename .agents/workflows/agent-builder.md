# Agent Builder

Define the task boundary before the prompt. Specify inputs, allowed tools, denied capabilities, budgets, stop conditions, output schema, failure behavior, observability, and evaluation fixtures. Prefer a narrow agent that fails closed over an agent with ambient credentials or unrestricted side effects.
