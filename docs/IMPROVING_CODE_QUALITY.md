## Overview

This document provides strategies and implementation details for improving the quality of code generated by ContribAI. The goal is to increase the PR merge rate from 26% to 50%+ by generating more maintainer-friendly, context-aware contributions.

## Current State Analysis

### Metrics (v4.1.0)
- **PR Merge Rate:** 26% (9/34 PRs)
- **Quality Score Average:** 7.5/10.0
- **False Positive Rate:** ~15%
- **Common Rejection Reasons:**
  - Code doesn't follow repo conventions
  - Missing context about project architecture
  - Over-engineering simple fixes
  - Breaking existing patterns

### Root Causes
1. **Generic prompts** - Not customized per repo
2. **Limited context** - Only sees file content, not conventions
3. **No semantic understanding** - Treats code as text
4. **Insufficient validation** - Quality gate too lenient

async def get_weekly_metrics(week_start: datetime) -> WeeklyReport:
    """Generate weekly metrics report."""
    
    # 1. Rejection reasons
    rejected_prs = await memory.get_prs_by_outcome("rejected", since=week_start)
    rejection_reasons = {}
    for pr in rejected_prs:
        reason = classify_rejection_reason(pr.feedback)
        rejection_reasons[reason] = rejection_reasons.get(reason, 0) + 1
    
    # 2. Review patterns
    all_prs = await memory.get_prs_since(week_start)
    review_patterns = {}
    for pr in all_prs:
        pattern = classify_review_pattern(pr.reviews)
        review_patterns[pattern] = review_patterns.get(pattern, 0) + 1
    
    # 3. Time metrics
    merged_prs = [pr for pr in all_prs if pr.outcome == "merged"]
    avg_time_to_merge = sum(pr.time_to_close_hours for pr in merged_prs) / len(merged_prs)
    avg_review_rounds = sum(len(pr.reviews) for pr in merged_prs) / len(merged_prs)
    
    # 4. Quality scores
    avg_style = sum(pr.style_score for pr in all_prs if pr.style_score) / len(all_prs)
    avg_minimalism = sum(pr.minimalism_score for pr in all_prs if pr.minimalism_score) / len(all_prs)
    
    return WeeklyReport(
        merge_rate=len(merged_prs) / len(all_prs),
        rejection_reasons=rejection_reasons,
        review_patterns=review_patterns,
        avg_time_to_merge=avg_time_to_merge,
        avg_review_rounds=avg_review_rounds,
        avg_style_score=avg_style,
        avg_minimalism_score=avg_minimalism,
    )


def classify_rejection_reason(feedback: str) -> str:
    """Classify rejection reason from feedback text."""
    feedback_lower = feedback.lower()
    
    # Style issues
    if any(kw in feedback_lower for kw in ["style", "format", "convention", "indent"]):
        return "style_mismatch"
    
    # Too many changes
    if any(kw in feedback_lower for kw in ["too many", "too much", "scope", "unrelated"]):
        return "too_many_changes"
    
    # Doesn't fix
    if any(kw in feedback_lower for kw in ["doesn't fix", "not fixed", "still broken"]):
        return "doesnt_fix_issue"
    
    # Over-engineered
    if any(kw in feedback_lower for kw in ["complex", "over", "simpler", "overkill"]):
        return "over_engineered"
    
    # Breaking
    if any(kw in feedback_lower for kw in ["break", "backward", "compatibility"]):
        return "breaking_changes"
    
    return "other"

from __future__ import annotations

import logging
import re
from dataclasses import dataclass

logger = logging.getLogger(__name__)


@dataclass
class RepoConventions:
    """Extracted conventions from a repository."""
    
    # Code style
    naming_convention: str  # snake_case, camelCase, PascalCase
    indentation: str  # spaces (2/4) or tabs
    quote_style: str  # single, double
    line_length: int  # max line length
    
    # Architecture patterns
    error_handling_pattern: str  # try/except, Result type, etc.
    async_pattern: str  # async/await, callbacks, promises
    testing_framework: str  # pytest, jest, go test
    
    # Documentation
    docstring_style: str  # Google, NumPy, JSDoc
    comment_density: str  # high, medium, low
    
    # Project-specific
    preferred_libraries: list[str]  # requests vs httpx, etc.
    forbidden_patterns: list[str]  # patterns to avoid
    
    @classmethod
    async def extract_from_repo(
        cls,
        repo: Repository,
        files: dict[str, str],
        llm: LLMProvider
    ) -> RepoConventions:
        """Extract conventions by analyzing existing code."""
        
        # Analyze naming patterns
        naming = cls._detect_naming_convention(files)
        
        # Analyze indentation
        indentation = cls._detect_indentation(files)
        
        # Analyze quote style
        quotes = cls._detect_quote_style(files)
        
        # Use LLM for complex pattern detection
        patterns_prompt = cls._build_pattern_detection_prompt(files)
        patterns_response = await llm.complete(patterns_prompt)
        patterns = cls._parse_patterns(patterns_response)
        
        return cls(
            naming_convention=naming,
            indentation=indentation,
            quote_style=quotes,
            line_length=patterns.get("line_length", 100),
            error_handling_pattern=patterns.get("error_handling", "try/except"),
            async_pattern=patterns.get("async_pattern", "async/await"),
            testing_framework=patterns.get("testing_framework", "pytest"),
            docstring_style=patterns.get("docstring_style", "Google"),
            comment_density=patterns.get("comment_density", "medium"),
            preferred_libraries=patterns.get("preferred_libraries", []),
            forbidden_patterns=patterns.get("forbidden_patterns", []),
        )
    
    @staticmethod
    def _detect_naming_convention(files: dict[str, str]) -> str:
        """Detect naming convention from code samples."""
        snake_case_count = 0
        camel_case_count = 0
        
        for content in files.values():
            # Count function/variable patterns
            snake_case_count += len(re.findall(r'\b[a-z]+_[a-z_]+\b', content))
            camel_case_count += len(re.findall(r'\b[a-z]+[A-Z][a-zA-Z]+\b', content))
        
        return "snake_case" if snake_case_count > camel_case_count else "camelCase"
    
    @staticmethod
    def _detect_indentation(files: dict[str, str]) -> str:
        """Detect indentation style."""
        spaces_2 = 0
        spaces_4 = 0
        tabs = 0
        
        for content in files.values():
            lines = content.split('\n')
            for line in lines:
                if line.startswith('  ') and not line.startswith('    '):
                    spaces_2 += 1
                elif line.startswith('    '):
                    spaces_4 += 1
                elif line.startswith('\t'):
                    tabs += 1
        
        if tabs > spaces_2 and tabs > spaces_4:
            return "tabs"
        elif spaces_2 > spaces_4:
            return "2 spaces"
        else:
            return "4 spaces"
    
    def to_prompt_context(self) -> str:
        """Convert conventions to prompt context."""
        return f"""
Repository Conventions:
- Naming: {self.naming_convention}
- Indentation: {self.indentation}
- Quotes: {self.quote_style}
- Max line length: {self.line_length}
- Error handling: {self.error_handling_pattern}
- Async pattern: {self.async_pattern}
- Testing: {self.testing_framework}
- Docstrings: {self.docstring_style}
- Preferred libraries: {', '.join(self.preferred_libraries)}
- Avoid: {', '.join(self.forbidden_patterns)}

CRITICAL: Your generated code MUST follow these conventions exactly.
"""
```

from __future__ import annotations

from dataclasses import dataclass
from enum import Enum


class ArchitecturePattern(str, Enum):
    """Common architecture patterns."""
    MVC = "mvc"
    MVVM = "mvvm"
    LAYERED = "layered"
    MICROSERVICES = "microservices"
    MONOLITH = "monolith"
    PLUGIN = "plugin"
    EVENT_DRIVEN = "event_driven"


@dataclass
class ProjectArchitecture:
    """Detected project architecture with confidence."""
    
    pattern: ArchitecturePattern
    confidence: float  # 0.0-1.0
    entry_points: list[str]
    core_modules: list[str]
    data_layer: list[str]
    api_layer: list[str]
    utility_modules: list[str]
    
    @classmethod
    def detect_from_tree(cls, tree: list[FileNode]) -> ProjectArchitecture:
        """Detect architecture from file tree with confidence score."""
        paths = [node.path for node in tree if node.type == "blob"]
        
        # Detect pattern with confidence
        pattern, confidence = cls._detect_pattern_with_confidence(paths)
        
        # Categorize files
        entry_points = [p for p in paths if cls._is_entry_point(p)]
        core_modules = [p for p in paths if cls._is_core_module(p)]
        data_layer = [p for p in paths if cls._is_data_layer(p)]
        api_layer = [p for p in paths if cls._is_api_layer(p)]
        utility_modules = [p for p in paths if cls._is_utility(p)]
        
        return cls(
            pattern=pattern,
            confidence=confidence,
            entry_points=entry_points,
            core_modules=core_modules,
            data_layer=data_layer,
            api_layer=api_layer,
            utility_modules=utility_modules,
        )
    
    @staticmethod
    def _detect_pattern_with_confidence(paths: list[str]) -> tuple[ArchitecturePattern, float]:
        """Detect architecture pattern with confidence score."""
        scores = {}
        
        # MVC indicators
        has_models = sum(1 for p in paths if "models" in p or "model" in p)
        has_views = sum(1 for p in paths if "views" in p or "view" in p)
        has_controllers = sum(1 for p in paths if "controllers" in p or "controller" in p)
        
        if has_models and has_views and has_controllers:
            mvc_confidence = min(has_models, has_views, has_controllers) / max(has_models, has_views, has_controllers)
            scores[ArchitecturePattern.MVC] = mvc_confidence
        
        # Layered architecture
        layer_keywords = ["domain", "application", "infrastructure", "presentation"]
        layer_count = sum(1 for p in paths for kw in layer_keywords if kw in p)
        if layer_count > 0:
            scores[ArchitecturePattern.LAYERED] = min(layer_count / len(layer_keywords), 1.0)
        
        # Plugin architecture
        plugin_count = sum(1 for p in paths if "plugin" in p)
        if plugin_count > 0:
            scores[ArchitecturePattern.PLUGIN] = min(plugin_count / 5, 1.0)
        
        # Return pattern with highest confidence
        if scores:
            best_pattern = max(scores, key=scores.get)
            return best_pattern, scores[best_pattern]
        
        return ArchitecturePattern.MONOLITH, 0.5  # Default with low confidence
    
    def to_prompt_context(self) -> str:
        """Convert architecture to prompt context."""
        confidence_note = ""
        if self.confidence < 0.7:
            confidence_note = f"\nNOTE: Architecture detection confidence is {self.confidence:.0%}. Treat as suggestion."
        
        return f"""
Project Architecture: {self.pattern.value.upper()} (confidence: {self.confidence:.0%}){confidence_note}

Entry Points:
{chr(10).join(f"  - {ep}" for ep in self.entry_points[:5])}

Core Business Logic:
{chr(10).join(f"  - {cm}" for cm in self.core_modules[:5])}

Data Layer:
{chr(10).join(f"  - {dl}" for dl in self.data_layer[:5])}

API Layer:
{chr(10).join(f"  - {al}" for al in self.api_layer[:5])}

IMPORTANT: 
- Changes to core modules require extra care
- API changes may need documentation updates
- Data layer changes may need migrations
"""
```

import logging
from dataclasses import dataclass

logger = logging.getLogger(__name__)


@dataclass
class MergedPRPattern:
    """Pattern extracted from merged PRs."""
    
    repo_id: str
    pr_number: int
    contribution_type: str
    
    # What worked
    code_style: str  # How code was formatted
    change_scope: str  # small, medium, large
    explanation_style: str  # technical, simple, detailed
    test_included: bool
    
    # Maintainer feedback
    positive_feedback: list[str]
    requested_changes: list[str]
    
    # Metrics
    time_to_merge_hours: float
    review_rounds: int


class PRPatternLearner:
    """Learn from merged PRs to improve future contributions."""
    
    def __init__(self, memory: Memory, github: GitHubClient):
        self._memory = memory
        self._github = github
    
    async def analyze_merged_prs(self, repo: Repository) -> list[MergedPRPattern]:
        """Analyze all merged PRs for a repo."""
        # Get merged PRs from memory
        outcomes = await self._memory.get_pr_outcomes(repo.id, outcome="merged")
        
        patterns = []
        for outcome in outcomes:
            # Fetch PR details
            pr = await self._github.get_pr(repo.owner, repo.name, outcome.pr_number)
            
            # Analyze PR
            pattern = await self._analyze_pr(repo, pr, outcome)
            patterns.append(pattern)
        
        return patterns
    
    async def _analyze_pr(
        self, 
        repo: Repository, 
        pr: dict, 
        outcome: PROutcome
    ) -> MergedPRPattern:
        """Analyze a single merged PR."""
        # Extract code style from diff
        diff = await self._github.get_pr_diff(repo.owner, repo.name, pr["number"])
        code_style = self._extract_code_style(diff)
        
        # Analyze change scope
        files_changed = pr.get("changed_files", 0)
        additions = pr.get("additions", 0)
        change_scope = self._categorize_scope(files_changed, additions)
        
        # Extract feedback from reviews
        reviews = await self._github.get_pr_reviews(
            repo.owner, repo.name, pr["number"]
        )
        positive_feedback, requested_changes = self._extract_feedback(reviews)
        
        return MergedPRPattern(
            repo_id=repo.id,
            pr_number=pr["number"],
            contribution_type=outcome.contribution_type,
            code_style=code_style,
            change_scope=change_scope,
            explanation_style=self._analyze_explanation(pr["body"]),
            test_included=self._has_tests(diff),
            positive_feedback=positive_feedback,
            requested_changes=requested_changes,
            time_to_merge_hours=outcome.time_to_close_hours,
            review_rounds=len(reviews),
        )
    
    def generate_best_practices(
        self, 
        patterns: list[MergedPRPattern]
    ) -> str:

        if not patterns:
            return ""
        
        # Aggregate patterns
        avg_scope = self._most_common([p.change_scope for p in patterns])
        avg_style = self._most_common([p.explanation_style for p in patterns])
        test_rate = sum(p.test_included for p in patterns) / len(patterns)
        
        # Extract common positive feedback
        all_positive = []
        for p in patterns:
            all_positive.extend(p.positive_feedback)
        top_positive = self._most_common_phrases(all_positive, top_n=3)
        
        return f"""
Best Practices (learned from {len(patterns)} merged PRs):

1. Change Scope: Keep changes {avg_scope}
2. Explanation Style: Use {avg_style} descriptions
3. Tests: {"Include tests" if test_rate > 0.5 else "Tests optional"}

What Maintainers Appreciated:
{chr(10).join(f"  - {feedback}" for feedback in top_positive)}

IMPORTANT: Follow these patterns for higher merge probability.
"""

# contribai/analysis/semantic_analyzer.py
from __future__ import annotations

import ast
import logging
from dataclasses import dataclass

logger = logging.getLogger(__name__)


@dataclass
class CodeEntity:
    """A code entity (function, class, variable)."""
    
    type: str  # function, class, variable, import
    name: str
    file_path: str
    line_start: int
    line_end: int
    
    # Relationships
    calls: list[str]  # Functions this entity calls
    called_by: list[str]  # Functions that call this entity
    imports: list[str]  # Modules this entity imports
    dependencies: list[str]  # Other entities this depends on


class SemanticAnalyzer:
    """Analyze code semantically using AST."""
    
    def __init__(self):
        self._entities: dict[str, CodeEntity] = {}
    
    def analyze_python_file(self, file_path: str, content: str) -> list[CodeEntity]:
        """Analyze Python file using AST."""
        try:
            tree = ast.parse(content)
        except SyntaxError as e:
            logger.warning(f"Syntax error in {file_path}: {e}")
            return []
        
        entities = []
        
        # Extract functions (sync and async)
        for node in ast.walk(tree):
            if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)):
                entity = self._extract_function(node, file_path, content)
                entities.append(entity)
            elif isinstance(node, ast.ClassDef):
                entity = self._extract_class(node, file_path, content)
                entities.append(entity)
        
        return entities
    
    def _extract_function(
        self, 
        node: ast.FunctionDef | ast.AsyncFunctionDef, 
        file_path: str,
        content: str
    ) -> CodeEntity:
        """Extract function entity (sync or async)."""
        # Find function calls
        calls = []
        for child in ast.walk(node):
            if isinstance(child, ast.Call):
                if isinstance(child.func, ast.Name):
                    calls.append(child.func.id)
                elif isinstance(child.func, ast.Attribute):
                    calls.append(child.func.attr)
        
        # Find imports
        imports = []
        for child in ast.walk(node):
            if isinstance(child, ast.Import):
                imports.extend(alias.name for alias in child.names)
            elif isinstance(child, ast.ImportFrom):
                if child.module:
                    imports.append(child.module)
        
        return CodeEntity(
            type="function",
            name=node.name,
            file_path=file_path,
            line_start=node.lineno,
            line_end=node.end_lineno or node.lineno,
            calls=calls,
            called_by=[],  # Will be populated later
            imports=imports,
            dependencies=[],
        )
    
    def build_dependency_graph(
        self, 
        entities: list[CodeEntity]
    ) -> dict[str, list[str]]:
        """Build dependency graph from entities."""
        graph = {}
        
        # Build call graph
        for entity in entities:
            graph[entity.name] = entity.calls
            
            # Update called_by relationships
            for called in entity.calls:
                for other in entities:
                    if other.name == called:
                        other.called_by.append(entity.name)
        
        return graph
    
    def find_impact_radius(
        self, 
        entity_name: str, 
        graph: dict[str, list[str]]
    ) -> list[str]:
        """Find all entities affected by changing this entity."""
        affected = set()
        queue = [entity_name]
        
        while queue:
            current = queue.pop(0)
            if current in affected:
                continue
            
            affected.add(current)
            
            # Find entities that depend on current
            for name, deps in graph.items():
                if current in deps and name not in affected:
                    queue.append(name)
        
        return list(affected)
    
    def to_prompt_context(
        self, 
        entity: CodeEntity, 
        graph: dict[str, list[str]]
    ) -> str:
        """Convert semantic analysis to prompt context."""
        impact = self.find_impact_radius(entity.name, graph)
        
        return f"""

Location: {entity.file_path}:{entity.line_start}-{entity.line_end}

from __future__ import annotations

import logging
from typing import Any

import numpy as np

logger = logging.getLogger(__name__)


class CodeEmbedder:
    """Generate embeddings for code snippets.
    
    NOTE: This requires LLM provider with embedding support.
    Fallback uses simple token-based embedding.
    """
    
    def __init__(self, llm: LLMProvider):
        self._llm = llm
        self._cache: dict[str, np.ndarray] = {}
    
    async def embed_code(self, code: str) -> np.ndarray:
        """Generate embedding for code snippet."""
        # Check cache
        if code in self._cache:
            return self._cache[code]
        
        # Use LLM to generate embedding
        try:
            embedding = await self._llm.embed(code)
            self._cache[code] = embedding
            return embedding
        except Exception as e:
            logger.warning(f"Failed to generate embedding: {e}")
            # Fallback: simple token-based embedding
            return self._simple_embedding(code)
    
    def _simple_embedding(self, code: str) -> np.ndarray:
        """Simple token-based embedding as fallback.
        
        WARNING: This is a weak fallback. Cosine similarity
        with this embedding is essentially bag-of-words matching.
        Use with caution and low confidence threshold.
        """
        # Count token frequencies
        tokens = code.split()
        vocab = list(set(tokens))
        
        # Create frequency vector
        vector = np.zeros(min(len(vocab), 100))
        for i, token in enumerate(vocab[:100]):
            vector[i] = tokens.count(token) / len(tokens)
        
        return vector
    
    async def find_similar_code(
        self,
        target_code: str,
        candidates: list[tuple[str, str]],  # (path, code)
        top_k: int = 5,
        min_similarity: float = 0.7  # Lowered from 0.8 for fallback embedding
    ) -> list[tuple[str, float]]:
        """Find most similar code snippets.
        
        Args:
            target_code: Code to find matches for
            candidates: List of (path, code) tuples to search
            top_k: Number of results to return
            min_similarity: Minimum similarity threshold (0.0-1.0)
        
        Returns:
            List of (path, similarity_score) tuples
        
        Note:
            If using fallback embedding, similarity scores may be less reliable.
            Consider using min_similarity=0.7 instead of 0.8 in that case.
        """
        target_embedding = await self.embed_code(target_code)
        
        similarities = []
        for path, code in candidates:
            candidate_embedding = await self.embed_code(code)
            similarity = self._cosine_similarity(target_embedding, candidate_embedding)
            if similarity >= min_similarity:
                similarities.append((path, similarity))
        
        # Sort by similarity
        similarities.sort(key=lambda x: x[1], reverse=True)
        return similarities[:top_k]
    
    @staticmethod
    def _cosine_similarity(a: np.ndarray, b: np.ndarray) -> float:
        """Calculate cosine similarity between two vectors."""
        return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))


class PatternMatcher:
    """Match code patterns using embeddings."""
    
    def __init__(self, embedder: CodeEmbedder):
        self._embedder = embedder
    
    async def find_similar_fixes(
        self,
        finding: Finding,
        repo_files: dict[str, str]
    ) -> list[str]:
        """Find similar code that might need the same fix."""
        # Get code around the finding
        target_file = repo_files.get(finding.file_path, "")
        lines = target_file.split('\n')
        
        start = max(0, finding.line_start - 5)
        end = min(len(lines), finding.line_end + 5)
        target_code = '\n'.join(lines[start:end])
        
        # Find similar code in other files
        candidates = []
        for path, content in repo_files.items():
            if path == finding.file_path:
                continue
            
            # Split into chunks
            chunks = self._split_into_chunks(content)
            for chunk in chunks:
                candidates.append((path, chunk))
        
        # Find most similar
        similar = await self._embedder.find_similar_code(
            target_code, 
            candidates, 
            top_k=5,
            min_similarity=0.7  # Adjusted for fallback embedding
        )
        
        return [path for path, score in similar]
    
    @staticmethod
    def _split_into_chunks(content: str, chunk_size: int = 10) -> list[str]:
        """Split content into overlapping chunks."""
        lines = content.split('\n')
        chunks = []
        
        for i in range(0, len(lines), chunk_size // 2):
            chunk = '\n'.join(lines[i:i + chunk_size])
            if chunk.strip():
                chunks.append(chunk)
        
        return chunks

import logging

logger = logging.getLogger(__name__)


@dataclass
class QualityScore:
    """Comprehensive quality score."""
    
    # Core metrics (0-10 each)
    correctness: float  # Fixes the issue
    style_match: float  # Matches repo style
    minimalism: float  # Minimal changes
    safety: float  # No bugs introduced

class EnhancedQualityScorer:
    """Enhanced quality scoring with stricter criteria."""
    
    def __init__(self, threshold: float = 7.5):
        self._threshold = threshold
    
    async def score(
        self,
        generated_code: str,
        original_code: str,
        finding: Finding,
        context: GenerationContext,
        conventions: RepoConventions
    ) -> QualityScore:
        """Score generated code comprehensively."""
        
        # 1. Correctness (most important)
        correctness = await self._score_correctness(
            generated_code, original_code, finding
        )
        
        # 2. Style match
        style_match = self._score_style_match(
            generated_code, original_code, conventions
        )
        
        # 3. Minimalism
        minimalism = self._score_minimalism(generated_code, original_code)
        
        # 4. Safety
        safety = await self._score_safety(generated_code, original_code)
        
        # 5. Backward compatibility
        backward_compatible = self._score_backward_compatibility(
            generated_code, original_code
        )
        
        # 6. Test coverage
        test_coverage = self._score_test_coverage(generated_code, context)
        
        # 7. Documentation
        documentation = self._score_documentation(generated_code, conventions)
        
        # 8. Performance
        performance = self._score_performance(generated_code, original_code)
        
        # Calculate total (weighted average)
        total = (
            correctness * 0.30 +  # 30% weight
            style_match * 0.20 +  # 20% weight
            minimalism * 0.15 +   # 15% weight
            safety * 0.15 +       # 15% weight
            backward_compatible * 0.10 +  # 10% weight
            test_coverage * 0.05 +  # 5% weight
            documentation * 0.03 +  # 3% weight
            performance * 0.02      # 2% weight
        )
        
        passed = total >= self._threshold
        
        # Collect issues and warnings
        issues = []
        warnings = []
        
        if correctness < 7.0:
            issues.append("Correctness score too low")
        if style_match < 6.0:
            issues.append("Style doesn't match repo conventions")
        if safety < 7.0:
            issues.append("Safety concerns detected")
        if minimalism < 5.0:
            warnings.append("Changes are not minimal")
        
        return QualityScore(
            correctness=correctness,
            style_match=style_match,
            minimalism=minimalism,
            safety=safety,
            backward_compatible=backward_compatible,
            test_coverage=test_coverage,
            documentation=documentation,
            performance=performance,
            total=total,
            passed=passed,
            issues=issues,
            warnings=warnings,
        )
    
    def _score_style_match(
        self,
        generated: str,
        original: str,
        conventions: RepoConventions
    ) -> float:
        """Score how well generated code matches style."""
        score = 10.0
        
        # Check naming convention
        if conventions.naming_convention == "snake_case":
            if not self._uses_snake_case(generated):
                score -= 2.0
        elif conventions.naming_convention == "camelCase":
            if not self._uses_camel_case(generated):
                score -= 2.0
        
        # Check indentation
        gen_indent = self._detect_indentation(generated)
        if gen_indent != conventions.indentation:
            score -= 2.0
        
        # Check quote style
        gen_quotes = self._detect_quote_style(generated)
        if gen_quotes != conventions.quote_style:
            score -= 1.0
        
        # Check line length
        max_line = max(len(line) for line in generated.split('\n'))
        if max_line > conventions.line_length + 10:
            score -= 1.0
        
        return max(0.0, score)
    
    def _score_minimalism(self, generated: str, original: str) -> float:
        """Score how minimal the changes are."""
        # Calculate diff size
        gen_lines = generated.split('\n')
        orig_lines = original.split('\n')
        
        # Count changed lines
        changed = 0
        for i, (g, o) in enumerate(zip(gen_lines, orig_lines)):
            if g != o:
                changed += 1
        
        # Add new/removed lines
        changed += abs(len(gen_lines) - len(orig_lines))
        
        # Score based on change ratio
        total_lines = len(orig_lines)
        change_ratio = changed / total_lines if total_lines > 0 else 1.0
        
        if change_ratio < 0.1:  # < 10% changed
            return 10.0
        elif change_ratio < 0.2:  # < 20% changed
            return 8.0
        elif change_ratio < 0.3:  # < 30% changed
            return 6.0
        elif change_ratio < 0.5:  # < 50% changed
            return 4.0
        else:
            return 2.0
    
    async def _score_safety(self, generated: str, original: str) -> float:
        """Score safety of generated code."""
        score = 10.0
        
        # Check for common issues
        if 'eval(' in generated or 'exec(' in generated:
            score -= 3.0
        
        if 'pickle.loads' in generated:
            score -= 2.0
        
        if 'yaml.load(' in generated and 'SafeLoader' not in generated:
            score -= 2.0
        
        # Check for SQL injection patterns
        if 'execute(' in generated and '%s' in generated:
            if 'cursor.execute' in generated:
                score -= 1.0
        
        # Check for unhandled exceptions
        try:
            tree = ast.parse(generated)
            for node in ast.walk(tree):
                if isinstance(node, ast.Try):
                    if not node.handlers:
                        score -= 1.0
        except SyntaxError:
            score -= 5.0  # Syntax error is critical
        
        return max(0.0, score)

## Known Risks & Mitigation

### Risk 1: Overfitting to Merged PRs

**Risk:** Learning from small sample of merged PRs may not generalize

**Indicators:**
- Merge rate increases for repos with history, but drops for new repos
- Generated code becomes too similar to past PRs
- Maintainers comment "this looks copy-pasted"

**Mitigation:**
- Require minimum 5 merged PRs before learning
- Cap learning samples at 20 per repo
- Add diversity penalty to prevent repetition
- A/B test: 50% with learning, 50% without

### Risk 2: Pipeline Cost & Latency Explosion

**Risk:** Multi-stage generation increases cost 3-5x and latency 2-3x

**Indicators:**
- LLM API costs increase >200%
- Time per repo increases from 2min to 6min+
- Daily throughput drops from 50 to 20 repos

**Mitigation:**
- Use fast mode by default (single-stage)
- Only use deep mode for high-severity findings
- Cache convention extraction (1 week TTL)
- Set timeout limits per stage

### Risk 3: False Confidence from Internal Scoring

**Risk:** High quality score doesn't predict maintainer acceptance

**Indicators:**
- PRs with 9.0+ score still get rejected
- Low correlation between score and merge rate
- Maintainers reject for reasons not in scorer

**Mitigation:**
- Track correlation: quality_score vs merge_outcome
- If correlation < 0.5, recalibrate scorer weights
- Add "maintainer feedback" as training signal
- Consider human-in-loop for critical repos

### Risk 4: Heuristic Brittleness

**Risk:** Convention/architecture detection fails on edge cases

**Indicators:**
- Generated code uses wrong style for 20%+ of repos
- Architecture detection confidence < 0.6 frequently
- Style match score drops instead of improving

**Mitigation:**
- Always show confidence scores
- Fallback to conservative defaults if confidence < 0.6
- Allow manual override via repo config
- Collect feedback on detection accuracy
